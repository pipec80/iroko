clean local reset, coverage, knip and justified check exceptions.

the existing LOCAL_VALIDATION isolation remains separate. CI validation jobs
explicitly disable uploads and pass no Sentry token.

Turbopack after-compile hook even with the individual effects disabled. The
guard stopped that executable before it ran. Authorization now also controls
`useRunAfterProductionCompileHook` and disables the Webpack bundler plugin via
`unstable_sentryWebpackPluginOptions.disable`; wrapper instrumentation is kept.
A test using the installed real wrapper confirms the tunnel is present and the
Turbopack upload hook is absent with authorization off. No Sentry CLI allowance
was introduced.

The local runner copies sources without environment/private files and uses
installed dependencies, synthetic observability configuration and local
credentials captured in RAM. Node network/child-process guards do not establish
OS-level network isolation. E2E remains explicitly unavailable until its local
fixtures and tunnel tests are adapted; it must not create fixtures while those
preconditions are missing.
