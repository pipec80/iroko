# Clasificación de previews

Estas páginas son muestras visuales, no código de producción ni una fuente de
tokens. El contrato vigente está en
[`../colors_and_type.css`](../colors_and_type.css).

## Vigentes

- `colors-source.html`, `colors-action.html`, `colors-accent.html`,
  `colors-neutrals.html`, `colors-semantic.html`, `colors-dark-preview.html`
- `type-body.html`, `type-display.html`, `type-headlines.html`,
  `type-labels.html`, `type-mono.html`, `type-scale.html`
- `comp-*.html`, `spacing-*.html` y `brand-*.html`

## Históricas

- `colors-iron.html`
- `colors-gold-indigo.html`
- `colors-bones.html`

Las tres muestras históricas reflejan una dirección retirada y se preservan
únicamente para trazabilidad. Un manifest o bundle generado puede seguir
listándolas; eso no las convierte en autoridad.
