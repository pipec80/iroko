01 / Personal anchor El más obvio
pipec/labs
studio · template · micro-saas

Pipec Labs — usa tu handle de siempre y lo eleva con "Labs", la convención dev-tool para taller experimental (Vercel Labs, Resend Labs, Anthropic Research). El dominio pipec.cl ya es tuyo.

  • Continuidad con tu identidad existente — no empiezas de cero
  • "Labs" señala maker / experimental / dev-first, no agencia de marketing
  • Funciona como paraguas: pipec/labs · pipec/ui · pipec/iot
  • El símbolo es una línea de pulso/heartbeat en bracket — IoT + telemetría

03 / Concept-driven El más conceptual
Núcleo
el kernel sobre el que se construye

Núcleo — la base/kernel sobre la que se construye. Tu template ES el núcleo de cada micro-SaaS que rebrandeas. Es spanish-native, tiene acento (carácter tipográfico), y se exporta directo a inglés sin perder sentido.

  • Mark = órbita atómica = robótica + automatización + IA
  • Funciona si lo monetizas como template (te lo "venden" a otros devs)
