Tres nombres· tres mitologías

Cada opción ancla en una cosmología distinta — Dogon, Yoruba, Akan — y propone una marca que pueda habitar un dashboard moderno sin perder su carga ritual. Los símbolos están dibujados con geometría sagrada: compás, eje, repetición.

01 · DOGON creadores gemelos
Nommo
ancestro · plataforma · principio

Nommo — en la mitología Dogon, los seres gemelos descendidos del cielo que trajeron el orden, el habla y el agua. Dos esferas, un eje vertical: dualidad cliente/servidor, frontend/backend, humano/máquina. Perfecto para un template que se duplica en cada micro-SaaS.

  • 5 letras · 2 sílabas · pronunciable en cualquier idioma
  • Símbolo = geometría sagrada limpia, escalable como favicon
  • Mitología del habla y el origen — encaja con plataforma / API
  • Disponibilidad razonable de dominio · .studio · .io · .systems

02 · YORUBA árbol sagrado
Iroko
tronco · ramas · cada cliente una rama

Iroko — el árbol sagrado yoruba al que se le pide permiso antes de cortarlo. La metáfora maps perfecta: un tronco compartido (tu template base + Supabase) y muchas ramas (cada micro-SaaS que rebrandeas crece de ahí). Cálido, terrenal, sin perder credibilidad técnica.

  • 5 letras · 3 sílabas · sonoridad cálida en español e inglés
  • Símbolo = árbol como diagrama modular — el SaaS-as-platform literalmente
  • Mitología del permiso y la raíz — ética + ancestralidad + tech
  • Espacio expansivo: Iroko Labs · Iroko Core · Iroko Roots

03 · AKAN retorno al origen
Sankofa
volver atrás · tomar · seguir

Sankofa — proverbio Akan: "no es tabú volver atrás por aquello que dejaste". El pájaro mira hacia atrás mientras carga un huevo: el futuro se construye recuperando el origen. Para una marca que rebrandeas en cada proyecto, es literalmente tu metodología.

  • 7 letras · 3 sílabas · símbolo Adinkra reconocido globalmente
  • El mark del pájaro+huevo es uno de los logos más narrativos que puedes tener
  • Carga ética clara: aprender del pasado para construir el futuro
  • Funciona como marca paraguas Y como nombre de cada producto-rama
